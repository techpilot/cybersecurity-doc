# Stephen Ngwu — Cybersecurity Journey

Full-stack engineer (co-founder & CTO, [SPOX](https://app.spox.trading)) making a documented, deliberate transition into Application Security. This repo is my public build log — daily notes, hands-on lab work, tools I write, and write-ups — on the way to an entry-level AppSec role and a funded master's in cybersecurity abroad.

I'm not starting from zero: I already own AppSec-adjacent work on SPOX (Auth0-based IAM, secrets management) and wanted a place to make the *deliberate study* half of this transition just as visible as the work half.

## Current focus
- **Lane:** Application Security
- **Certifications:** Google Cybersecurity Professional Certificate · GRC Afriq
- **Hands-on:** HackTheBox (Level 5, Beginner rank) · home lab (Kali Linux vs OWASP Juice Shop)

## How this repo is organized

| Folder | What's in it |
|---|---|
| `notes/appsec/` | One file per vulnerability class — mechanism, a real breach, how to test it, how to fix it |
| `notes/networking/` | Same idea, for networking/infra fundamentals |
| `notes/reading-log.md` | Short daily log of what I read and the one takeaway that mattered |
| `labs/` | Findings from my own home lab (Kali VM vs OWASP Juice Shop, etc.) |
| `labs/htb-progress.md` | HackTheBox log — skills used and date, **no flags/spoilers for active machines** |
| `tools/` | Small scripts I build to actually use what I studied, not just read about it |
| `writeups/` | Full write-ups — **retired** HTB machines / TryHackMe rooms / my own labs only |
| `projects/` | Bigger pieces — audits, incident-handler-journal-style work, the SPOX AppSec case study |

## Cadence
Updated daily, small entries most days, one deeper write-up or project push most weeks. The commit history is the actual proof of consistency — that's the point of doing this in the open.
